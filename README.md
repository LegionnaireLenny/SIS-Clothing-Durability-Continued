## SIS-Clothing-Durbility-Continued
This is an update to SweetCaptn's mod, SIS Clothing Durability https://steamcommunity.com/sharedfiles/filedetails/?id=3261720409, that fixes a few bugs. This mod replaces the original mod, so do not use them together. This was tested on the publicbeta version.

### Changelog

#### Version 1.1.0
- Fixed clothing repair option not appearing in inventory context menu
- Fixed repairing clothes randomizing the appearance of the repaired item
- Fixed degradation on attack not checking if degradation is enabled for the attacking character
- Fixed degradation on attack not degrading when attacking while unarmed
- Fixed logging
- Removed loose audio files since they're located in the asset bundle
- Code cleanup and refactoring
